用旧速度，
还是新速度？

上一节的 0.23 m 符合算法，却偏离精确位置 0.26 m。这一节只改位置更新使用的速度，看看结果怎样变化。

对应原书 §1.4 · Symplectic Euler · 建议 10–15 分钟

01 / 先算新速度，再用它更新位置

这叫 Symplectic Euler（辛 Euler），常见于半隐式 Euler 的表述。先记住更新顺序，“辛”的数学含义留到后面。

新速度 = 旧速度 + Δt × 当前加速度
新位置 = 旧位置 + Δt × 新速度

对照上一节：前向 Euler 的位置公式用的是旧速度。两个方法都从当前状态计算本步的加速度。

对应 原书 §1.4 的公式 1.4.2 与 1.4.3。本节采用书中的先速度、后位置这一种辛 Euler 更新顺序。

对应到程序：这一行改变了什么？
# 当前状态下求得的加速度；这里是一维质点
a = force / mass
v_next = v + dt * a
x_next = x + dt * v_next
x, v = x_next, v_next

前向 Euler 的位置行是 x_next = x + dt * v。关键在于引用哪个速度变量；单纯调换两行书写顺序，不一定改变算法。

02 / 仍然算同一个物体

质量 2 kg、恒定向右合力 6 N，因此 a = 3 m/s²。初始 x⁰ = 0 m、v⁰ = 1 m/s；步长为 0.1 s。

步骤先算速度再算位置
第 1 步1 + 0.1 × 3 = 1.30 + 0.1 × 1.3 = 0.13
第 2 步1.3 + 0.1 × 3 = 1.60.13 + 0.1 × 1.6 = 0.29

速度单位 m/s，位置单位 m。

0.29 m 也有误差。在这个速度持续增加的例子中，起点速度偏低、终点速度偏高；前向 Euler 少算位移，这种辛 Euler 多算位移。

精确位置为 x(t) = t + 1.5t²，故 x(0.2) = 0.26 m。这里两个方法的速度都恰好精确，因为加速度恒定。

03 / 缩小步长，会怎样？

固定比较 t = 0.2 s 的位置。改变步长时，也改变步数，让两个方法始终模拟相同的时长。

需要执行 2 步。偏差定义为“数值位置 − 精确位置”。

方法位置（m）偏差（m）
前向 Euler0.230−0.030
辛 Euler0.290+0.030
精确解0.2600

步长减半，需要的步数翻倍；观察两个偏差怎样变化。

这个恒力算例中，两种方法的位置偏差大小相同、方向相反。选用新速度不会自动让每一步的位置更准确。

用平均速度，能不能算准？

本例加速度恒定，因此一步内的平均速度恰好是 (旧速度 + 新速度)/2。第一步的位移为 (1 + 1.3)/2 × 0.1 = 0.115 m；第二步的位移为 (1.3 + 1.6)/2 × 0.1 = 0.145 m，合起来正好 0.26 m。

力随状态变化时，终点速度本身也可能有误差，端点平均也未必等于整段时间的真实平均。之后会继续讨论怎样构造更准确的积分方法。

04 / 那为什么还要学辛 Euler？

我们还关心长时间计算的行为。准确性关心数值结果离精确结果多远；在下面的振动例子中，稳定性关心计算得到的运动是否会无界增长。

进阶例子：没有阻尼的弹簧

设一个质量 1 kg 的质点沿直线连接弹簧，刚度为 1 N/m，平衡点为 x = 0。弹簧合力 f = −kx：偏向右侧时，力把它拉向左侧。初始 x = 1 m、v = 0，取 Δt = 0.1 s。

此模型精确运动的机械能 E = ½mv² + ½kx² 始终为 0.5 J。按两种离散公式计算：

时间（s）前向 Euler 能量（J）辛 Euler 能量（J）
00.5000000.500000
50.8223160.516007
101.3524070.477815
203.6580090.483734

这组教学计算里，前向 Euler 的能量持续增加，辛 Euler 的能量在精确值附近波动。有界波动仍然包含误差，并不表示逐步精确守恒。

对这个无阻尼线性弹簧模型，辛 Euler 在 0 < Δt√(k/m) < 2 时保持有界振动。这里的界限来自此模型的离散方程；其他模型需要重新分析。

表格为根据上述公式独立计算的教学数值，未调用物理引擎。两种积分公式见原书 §1.4；结论限定于这里说明的线性弹簧。

今天先掌握更新顺序，并记住：比较方法时，需要分别检查误差与稳定性。

05 / 换个状态，你来算

一个一维节点当前 x = 1 m、v = 0 m/s，算得当前加速度 a = −4 m/s²。取 Δt = 0.1 s，用先速度、后位置的辛 Euler推进一步。
