把运动方程
变成一次更新

今天的目标：给定当前位置、速度、合力和步长，亲手算出下一步的位置与速度。先用一个沿直线运动的质点。

对应原书 §1.3 与 §1.4 的 Forward Euler 部分 · 建议 10–15 分钟

01 / 给时间划小格

上一节我们知道 a = f/m，也知道速度描述位置变化得多快。程序需要进一步回答：经过一小段时间，位置和速度具体变成多少？

0 秒 → 0.1 秒 → 0.2 秒 → 0.3 秒 → …

这里每格长 0.1 秒，叫时间步长，记作 Δt。“Δ”表示变化量，因此 Δt 就是这一小段时间。

符号用人话说
n当前是第几步，从 0 开始数
xn、vn当前的位置和速度
xn+1、vn+1下一步的位置和速度

这里右上角的 n 是时间步编号。例如 x² 表示“第 2 步的位置”，此处不表示 x 的平方。

阅读 原书 §1.3 · Time Integration，先对上这些符号即可。

02 / 用当前变化率估计这一小步

速度为 1 m/s，经过 0.1 s，大约移动 1 × 0.1 = 0.1 m。同样，加速度为 3 m/s²，经过 0.1 s，速度大约增加 3 × 0.1 = 0.3 m/s。

Forward Euler（前向 Euler）把这一思路写成两条更新规则：

xn+1 = xn + Δt · vn
vn+1 = vn + Δt · an

一维质点的 an = fn/m。两个式子右侧都使用当前时刻的已知量，直接算出新的状态。

想看导数如何变成这个公式

用“一小段时间内的变化量 ÷ 时间长度”近似当前导数：

(xn+1 − xn)/Δt ≈ vn

在数值算法中，把选定的近似关系作为更新规则，两边乘 Δt，再加上 xn，就得到上面的位置公式。速度的推导完全类似。

公式对应 原书 §1.4 · Forward Euler。本节先学这一种更新规则。

03 / 一起算第一步

设质点质量 2 kg，持续受到向右 6 N 的合力；初始位置 0 m，初始速度向右 1 m/s。取向右为正，Δt = 0.1 s。

计算代入数字结果
当前加速度6 ÷ 23 m/s²
下一步位置0 + 0.1 × 10.1 m
下一步速度1 + 0.1 × 31.3 m/s

位置更新用了旧速度 1 m/s。如果在位置公式里代入新速度 1.3 m/s，就已经换了一种更新规则；这会在下一节比较。

对应到程序变量
# 一维质点；这里 force 是当前时刻的合力
acceleration = force / mass
x_next = x + dt * v
v_next = v + dt * acceleration

# 两个新值都算好后，再写回状态
x, v = x_next, v_next

对于位置、速度和力组成的向量，更新思路相同；加速度通过 M a = f 得到。

05 / 为什么说它是近似？

这个例子在第一步内一直受力，所以速度会从 1 增至 1.3 m/s。前向 Euler 却用起点速度 1 m/s 来估计整步的位移。

与恒定加速度的精确结果对照

恒定加速度下，精确位置为 x(t + Δt) = x(t) + v(t)Δt + ½aΔt²。因此第一步的精确位置是 0.115 m，而前向 Euler 算得 0.100 m，相差 0.015 m。

本例的速度更新恰好精确，因为加速度恒定。其他模型的力可能随位置、速度变化。这里的结论只针对这个构造的恒力算例。

时刻前向 Euler 位置精确位置
0.1 s0.100 m0.115 m
0.2 s0.230 m0.260 m

练习反馈检查的是是否正确执行离散公式；位置预测仍然可能有误差。

今天只需记住：时间积分选定了如何用有限的计算，近似这一段连续运动。
