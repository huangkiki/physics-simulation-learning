为什么隐式积分
需要解方程？

今天只抓住一件事：当力取决于下一时刻的位置，新位置和新速度就需要一起确定。用一个一维弹簧，把这组方程解出来。

对应原书 §1.5 的 Backward Euler 方程 · 建议 10–15 分钟

01 / 换一个力：弹簧会随位置改变

观看提示：先观察位置、力和速度怎样变化。画面中的 x(t) = cos(2t) 是本例提前给出的精确运动参照；它的含义与数字 2 的来源见第 05 部分。计算本节的后向 Euler，只需要下面的弹簧力关系。

前面的恒力例子中，合力始终是 6 N。现在让质量为 1 kg 的节点沿直线连接一根弹簧，刚度 k = 4 N/m。

令 x 表示节点相对平衡位置的偏移，向右为正。弹簧力写成：

f(x) = −kx = −4x

例如 x = 1 m 时，力为 −4 N，即向左拉；x = 0.5 m 时，力为 −2 N。这里的 f(x) 表示“根据位置 x 算出力”。

负号说明力指向平衡位置。k 的单位为 N/m，乘以偏移 x（m）以后得到力（N）。

02 / 把力也放到下一时刻

先回顾：三种 Euler 各用哪个时刻的量？

下面统一使用“旧”和“新”，表示同一步开始和结束的状态；Δt 是步长，m 是质量。限定为本例这种质量恒定、力只依赖位置的模型，f(位置)/m 就是该位置对应的加速度。

① 前向 Euler：用旧状态算这一步

新速度 = 旧速度 + Δt × f(旧位置)/m
新位置 = 旧位置 + Δt × 旧速度

两个右侧都用旧状态。即使程序先算出了新速度，更新位置时仍要保留并使用旧速度。

② 辛 Euler：先更新速度，再用新速度更新位置

新速度 = 旧速度 + Δt × f(旧位置)/m
新位置 = 旧位置 + Δt × 新速度

这是前面学过的“先速度、后位置”版本。力仍由旧位置计算，新速度算出来后，就能直接更新位置。

③ 后向 Euler：力也由新位置计算

新速度 = 旧速度 + Δt × f(新位置)/m
新位置 = 旧位置 + Δt × 新速度

后向 Euler（Backward Euler）是一种隐式积分方法：本例的新位置和新速度需要一起求解。

方法用哪个位置算力？用哪个速度更新位置？
前向 Euler旧位置旧速度
辛 Euler旧位置新速度
后向 Euler新位置新速度
代入同一个弹簧，看看第一步的数字

统一从旧 x = 1 m、旧 v = 0 开始，m = 1 kg、f(x) = −4x、Δt = 0.1 s。前向与辛 Euler 都先得到旧力 −4 N、旧加速度 −4 m/s²，因此新速度都为 0 + 0.1 × (−4) = −0.4 m/s。

前向：新位置 = 1 + 0.1 × 0 = 1 m
辛：新位置 = 1 + 0.1 × (−0.4) = 0.96 m

前向 Euler 这一步的位置没有变，是因为位置公式使用了值为 0 的旧速度；连续模型中的物体在这段时间内已经发生位移。

后向 Euler 则要联立 vnew = −0.4xnew 与 xnew = 1 + 0.1vnew。下一部分逐步解这两条式子，结果汇总如下：

方法新位置（m）新速度（m/s）
前向 Euler1.000000−0.400000
辛 Euler0.960000−0.400000
后向 Euler0.961538−0.384615

这些是各方法定义的一步数值结果。它们与连续模型精确解的差别，见第 05 部分；不能仅凭“用了新值”就判定一定更准确。

回顾来源：原书 §1.4，前向与辛 Euler；也可以返回第二节、第三节或查看三种 Euler 速查。

这里发生了互相依赖：

新位置 → 新弹簧力 → 新速度 → 新位置

我们要解出一对同时满足两个式子的新位置、新速度。方程右侧出现了还没有求出的未知量，这就是本例“隐式”的含义。名称里的“后向”对应从下一时刻回看这一段时间的差分方式；仿真仍然从当前时刻推进到下一时刻。

公式与状态依赖关系来自 原书 §1.5 · Backward Euler，式 1.5.1。弹簧参数和下面的手算例子是教学构造。

03 / 用代入法，把它解出来

当前 x = 1 m、v = 0 m/s，步长 Δt = 0.1 s。下面所有数字均使用对应的 SI 单位。

先把已知量代入两个更新式：

vnew = 0 + 0.1 × (−4xnew) = −0.4xnew
xnew = 1 + 0.1vnew

第一行已经把新速度表示成了新位置的函数。将它代入第二行：

xnew = 1 + 0.1 × (−0.4xnew)
xnew = 1 − 0.04xnew

把右边含新位置的项移到左边：

1.04xnew = 1
xnew = 1/1.04 ≈ 0.961538 m
vnew = −0.4/1.04 ≈ −0.384615 m/s

这个结果同时满足位置更新和速度更新。在新的位置，弹簧力约为 −3.846154 N。

和上一节的辛 Euler 有什么区别？

同一初始状态、相同步长下，辛 Euler 先用旧位置 1 m 算出力 −4 N，再得到新速度 −0.4 m/s、新位置 0.96 m。后向 Euler 用求解得到的新位置计算本步所用的力。

区别落在力在哪个状态计算。本节后向 Euler 的数值结果也仍然是时间离散的近似。

04 / 候选位置能让两条式子对上吗？

先试一个新位置 z，用速度方程算出 v，再用位置方程回算一次。如果回算的位置和 z 相同，两条关系就一致。

计算关系代入结果
新力 f(z) = −4z−4.000000 N
新速度 v = −0.4z−0.400000 m/s
回算位置 1 + 0.1v0.960000 m
残差 r = z − 回算位置0.040000 m

候选位置 1 m 回算后为 0.96 m，相差 0.04 m，两个式子还没有对上。

这里的“残差”就是把候选值代入离散方程后剩下的差。本例可写成 r(z) = 1.04z − 1。残差接近零，说明方程满足得好。

残差小，与真实运动误差小，是两个问题。把近似方程解得很充分，仍然可能留下时间离散误差。

05 / 解出来了，物理上就精确了吗？

前面已经建立的关系是：

f = −kx，a = f/m
所以 a = −(k/m)x，本例为 a = −4x

这告诉我们在某个位置时，加速度是多少。要得到“任意时刻的位置”，还需要结合初始位置和初始速度，求解连续运动方程。这一步此前没有展开，不能直接当作已经学过的结论。

下面提前给出精确解，作为检查误差的参照。适用条件：无阻尼、只有线性弹簧力作用于运动方向，m = 1 kg、k = 4 N/m，从 x = 1 m、v = 0 开始。本节的 Euler 手算不依赖余弦公式；想了解其来源，可以展开下面的求导说明。

先读懂 x(t) = cos(2t)

x(t) 读作“t 时刻的位置”，不是 x 乘以 t。这里 t 用秒、x 用米记数；cos 是余弦函数，数值会平滑地在 1 和 −1 之间往复变化。这条公式描述物体从右侧 1 m 处出发，经过平衡位置，到达左侧 −1 m，再返回。

x(t) = cos(2t)
x(0.1) = cos(0.2) ≈ 0.980067 m

括号里的 2 控制往复变化的快慢。它由本例的质量和刚度决定，来源见下方补充；它不表示每秒往复两次。

展开：把几个时刻代进去，和动画对照
时间 t（s，约）位置 x(t)（m）对应画面
01右侧最远处
0.7850经过平衡位置，向左
1.571−1左侧最远处
2.3560经过平衡位置，向右
3.1421回到右侧，完成一次往复

这里 cos 的输入采用弧度，计算器需选择 RAD。弧度也是表示角度的方法，一整圈是 2π 弧度，约为 6.283。cos 的输入增加 2π，数值重复一轮；本例输入是 2t，所以一次往复需要 π 秒，约 3.142 秒。

表中时间作了四舍五入；动画也放慢了播放，播放器的观看秒数不等于模型中的物理时间。

进阶选读：数字 2 从哪里来？为什么有 √(k/m)？

这里补充一个此前未讲过的求导步骤。“位置对时间求一次导数得到速度，再求一次得到加速度”。如果求导还不熟悉，可以先保留这个问题，不影响前面的 Euler 计算。

先用一个待定的正数 c 表示往复变化的快慢，试着用 x(t) = cos(ct) 描述本例从 1 m 处静止释放的运动。以下按秒、米记数。余弦和正弦的求导规则给出：

位置：x(t) = cos(ct)
↓ 对时间求导
速度：v(t) = −c sin(ct)
↓ 再对时间求导
加速度：a(t) = −c² cos(ct) = −c²x(t)

这里 sin 是正弦函数。具体规则是：cos(ct) 求导得到 −c sin(ct)，sin(ct) 求导得到 c cos(ct)；里面的 ct 使每次求导都带出一个 c，连续两次就出现 c²。

弹簧定律要求 a = −(k/m)x；这条余弦轨迹算出的加速度为 a = −c²x。要让它们在整个运动过程中一致，就需要：

c² = k/m
c = √(k/m)
本例：c = √(4/1) = 2

平方根来自对 c² = k/m 求解。这个 c 通常写作 ω（omega），称为角频率，本例为 2 rad/s。带上单位，位置公式完整写作 x(t) = (1 m) cos[(2 rad/s)t]。

还要检查起点：t = 0 时，cos(0) = 1、sin(0) = 0，于是 x(0) = 1 m、v(0) = 0。这样就验证了 x(t) = cos(2t) 同时符合运动方程和本例的初始条件。改变初始条件，位置公式也要相应改变。

补充阅读：OpenStax《University Physics》§15.1，位置、速度、加速度关系及角频率式 15.9。本例数字由这些关系代入得到。

再与这一步的结果比较

在同一个 t = 0.1 s 时刻：

精确速度由上面的 v(t) = −2sin(2t) 代入得到。离散方程可以解得很准确，但它描述的一步运动仍有时间离散误差。这里的“精确”限定于上述理想弹簧模型。

进阶选读：为什么这个无阻尼模型也会越算越不动？

该模型没有物理阻尼。后向 Euler 却会让每一步机械能乘上 1/(1 + 4Δt²)：这是数值耗散。此处的具体关系只适用于我们定义的线性弹簧模型。

今天把两项工作分开记：时间积分先规定这一步要满足的离散关系，求解方法再找出满足这些关系的数值。

06 / 为什么接下来要学 solver？

本例的残差 1.04z − 1 对未知量 z 是线性的，移项和除法就能求解。更多节点会形成联立方程；如果力对位置的关系是非线性的，求解过程还会更复杂。
