后向 Euler 与求解

限定为恒定质量、力只依赖位置的一维模型。多分量版本用质量矩阵。

vnew = v + Δt · f(xnew)/m
xnew = x + Δt · vnew

力、新速度、新位置一起确定。把速度消去，得到只含新位置 z 的方程：

r(z) = z − x − Δt · v − Δt² · f(z)/m = 0

本卡的 r 采用位置单位。把它乘以质量 m，可得到与教材式 1.5.2 对应的形式；零点不变。

概念用途
离散方程规定一步更新要满足什么关系
求解找出满足关系的未知数
残差候选值代入方程后剩下的差
时间离散误差数值轨迹与连续模型精确轨迹的偏差

线性弹簧 f(z) = −kz 可直接求解：

z = (x + Δt · v)/(1 + Δt² · k/m)

小残差说明所定义的方程满足得好；物理准确性还需要对照连续模型或独立参照。

精确参照：适用条件与来源

第四节另给了连续模型的精确解，用于检查时间离散误差。条件是无阻尼、运动方向只有线性弹簧力，m = 1 kg、k = 4 N/m，初始 x = 1 m、v = 0。

x(t) = cos(2t)
v(t) = −2sin(2t)

这里按秒、米记数，三角函数采用弧度。x(t) 表示 t 时刻的位置。数字 2 的来源是：cos(ct) 对时间连续求导两次得到 −c²cos(ct)，而弹簧方程要求 a = −(k/m)x，所以 c² = k/m，取正值得 c = √(k/m) = 2。它是角频率（rad/s）；本例一次往复约为 3.142 s。

这段用到了求导，是额外补充。Euler 的更新计算只需要力与状态的关系，不要求预先知道精确解。返回逐步解释与时间代入表。
