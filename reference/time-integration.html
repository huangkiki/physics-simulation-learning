前向 Euler

本卡限定为恒定质量、直角坐标下的位置与速度更新。

记号含义
Δt一步的时间长度
上标 n / n + 1当前步 / 下一步；这里是步编号
aⁿ当前加速度：一维为 fⁿ/m；多分量求 M aⁿ = fⁿ
xn+1 = xn + Δt · vn
vn+1 = vn + Δt · an

位置更新使用旧速度。先用旧状态算出两个新值，再写回。

a = force / mass
x_next = x + dt * v
v_next = v + dt * a
x, v = x_next, v_next

代码是一维质点形式。前向 Euler 用当前变化率估计有限时间内的变化。

单位核对：s × m/s = m；s × m/s² = m/s。

更换用于位置更新的速度时刻，会改变积分方法。

来源：原书 §1.3、§1.4 · Forward Euler。
