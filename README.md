# Physics Simulation Learning

面向初学者的物理仿真互动课程，按日期记录学习内容和预计学习时长。

## 在线学习

打开 [GitHub Pages 课程网站](https://huangkiki.github.io/physics-simulation-learning/)。

当前内容包括：

- 状态、方程与质量矩阵
- Forward Euler、Symplectic Euler 与 Implicit Euler
- Newton 迭代的直觉解释
- MPM 的 P2G、网格更新、G2P 与粒子更新流程
- IPC 的距离屏障、CCD、防穿透与摩擦直觉
- PIC、FLIP 与 APIC 的传输差异
- 形变梯度 F、弹性与塑性
- IPC 点—边距离的最近点判断

学习进度与四节进阶课的目标完成时间保存在当前浏览器本地；手机和电脑分别记录各自的数据。

## 本地打开

直接打开 `index.html`，或者在本目录运行：

```bash
python3 -m http.server 8766
```

然后访问 `http://127.0.0.1:8766/`。
